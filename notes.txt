how to start with python venv
- py -m venv .venv
- .venv\Scripts\activate
- pip install -r requirements.txt

serving on render with gunicorn
- update build command to install gunicorn and gevent:
  > pip install -r requirements.txt; pip install gunicorn gevent
- update start command to use gunicorn with gevent
  > gunicorn -k gevent -w 1 main:app
